================================================== PARTE 1. MYSQL – BASE DE DATOS RELACIONAL
RESTAURAR LA BASE DE DATOS MEDIANTE CONSOLA

Abrir CMD o terminal y ejecutar:

mysql -u root -p

Para restaurar el archivo SQL:

mysql -u root -p < respaldo_edutech.sql

Si el archivo está en otra ubicación:

mysql -u root -p < "C:\Users\Usuario\Downloads\respaldo_edutech.sql"

Verificar las bases de datos:

SHOW DATABASES;

Seleccionar la base de datos:

USE edutech;

Verificar las tablas:

SHOW TABLES;

APLICAR REGLAS DE NEGOCIO

A. CORREO ELECTRÓNICO ÚNICO PARA ESTUDIANTES

ALTER TABLE estudiantes ADD CONSTRAINT uq_correo UNIQUE (correo);

B. VALIDAR EL NIVEL DE LOS CURSOS

ALTER TABLE cursos ADD CONSTRAINT chk_nivel CHECK (nivel IN ('Básico', 'intermedio', 'avanzado'));

C. CONTROLAR EL NÚMERO DE ESTUDIANTES PERMITIDOS

ALTER TABLE cursos ADD CONSTRAINT chk_cupos CHECK (numero_estudiantes BETWEEN 10 AND 60);

Nota: Adaptar numero_estudiantes al nombre real de la columna de cupos de la tabla cursos. Las restricciones CHECK requieren MySQL 8.0.16 o superior para aplicarse efectivamente.

CREAR LAS VISTAS

A. VISTA DE ESTUDIANTES Y CURSOS

CREATE VIEW vista_estudiantes_cursos AS SELECT e.nombre AS nombre_estudiante, c.nombre AS nombre_curso, m.fecha_matricula, c.nivel FROM estudiantes e INNER JOIN matriculas m ON e.id_estudiante = m.id_estudiante INNER JOIN cursos c ON m.id_curso = c.id_curso;

Consultar:

SELECT * FROM vista_estudiantes_cursos;

B. VISTA DE CURSOS E INSTRUCTORES

CREATE VIEW vista_cursos_instructores AS SELECT c.nombre AS nombre_curso, i.nombre AS nombre_instructor, i.especialidad FROM cursos c INNER JOIN instructores i ON c.id_instructor = i.id_instructor;

Consultar:

SELECT * FROM vista_cursos_instructores;

CREAR USUARIOS Y ASIGNAR PRIVILEGIOS

A. USUARIO ADMINISTRADOR

CREATE USER 'administrador'@'localhost' IDENTIFIED BY 'Admin123*';

GRANT ALL PRIVILEGES ON edutech.* TO 'administrador'@'localhost';

B. USUARIO DE CONSULTAS

CREATE USER 'consultas'@'localhost' IDENTIFIED BY 'Consulta123*';

GRANT SELECT ON edutech.vista_estudiantes_cursos TO 'consultas'@'localhost';

GRANT SELECT ON edutech.vista_cursos_instructores TO 'consultas'@'localhost';

Actualizar privilegios:

FLUSH PRIVILEGES;

Verificar permisos:

SHOW GRANTS FOR 'administrador'@'localhost';

SHOW GRANTS FOR 'consultas'@'localhost';

CREAR LOS TRIGGERS

A. TRIGGER PARA ELIMINAR MATRÍCULAS CUANDO SE ELIMINE UN CURSO

DELIMITER //

CREATE TRIGGER eliminar_matriculas_curso BEFORE DELETE ON cursos FOR EACH ROW BEGIN

DELETE FROM matriculas
WHERE id_curso = OLD.id_curso;


END //

DELIMITER ;

Explicación: Cuando se elimina un curso, el trigger elimina automáticamente todas las matrículas asociadas a ese curso.

B. TRIGGER PARA REDUCIR LOS CUPOS DISPONIBLES

DELIMITER //

CREATE TRIGGER reducir_cupos AFTER INSERT ON matriculas FOR EACH ROW BEGIN

UPDATE cursos
SET cupos_disponibles = cupos_disponibles - 1
WHERE id_curso = NEW.id_curso;


END //

DELIMITER ;

Explicación: Cada vez que se registra una matrícula, se reduce automáticamente en uno la cantidad de cupos disponibles.

IMPORTANTE: Se recomienda agregar una validación BEFORE INSERT para impedir nuevas matrículas cuando los cupos disponibles sean cero.
